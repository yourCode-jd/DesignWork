# Jaspreet Singh — portfolio

Static site: `index.html`, `caseStudy*.html`, `projects/*.html`, `css/`, `js/`, `vendor/` (Swiper, GSAP).

- Tailwind is precompiled into `css/tailwind.generated.css` (Tailwind v3 CLI). If you add new Tailwind classes, rebuild it.
- Open `index.html` through a local server (the repo used Live Server on port 5501).
- Search the project for `ADD NUMBER` and `CONFIRM` — hidden HTML comments that mark where a real, verifiable number or quote belongs. Nothing renders from them.
