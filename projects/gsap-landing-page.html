Case Study

GSAP Landing Page

Interactive landing page built with scroll-based animations and smooth motion design.

Role: UI/UX + Frontend GSAP · ScrollTrigger · Motion

Goal

Build a landing page with responsive, scroll-linked animation that behaves correctly across breakpoints and doesn't leak memory or break on window resize — the kind of detail that separates a demo from something production-ready.

Development

  • Built with vanilla JavaScript and GSAP (core, ScrollTrigger, and Draggable). Uses gsap.matchMedia() to scope different animation behavior to different breakpoints, so mobile and desktop get intentionally different treatment rather than the same animation scaled down.
  • All animations are wrapped in gsap.context(), which scopes GSAP's selectors to a specific container and provides a single .revert() call to clean up every animation and event listener it created.

UI Screens

Challenges & Solutions

  • Making scroll and drag animations behave correctly across screen sizes — solved with matchMedia-scoped breakpoint rules instead of one animation set forced to work everywhere.
  • Avoiding the classic GSAP/ScrollTrigger memory-leak trap where animations and listeners pile up on resize — solved by scoping everything through gsap.context() for clean teardown.

Tech Stack & Links

HTML5 · CSS3 · Tailwind CSS · JavaScript · GSAP (core, ScrollTrigger, Draggable)
