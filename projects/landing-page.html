PulseFitCoach

A personal-coaching landing page with a draggable before/after comparison slider, animated split-title reveals, and a GSAP-powered mobile navigation drawer.

Role: UI/UX + Frontend HTML · CSS · JavaScript · GSAP

Goal

Build a coaching landing page with interaction that actually does something — a real before/after comparison the visitor can drag through, not just a static image, plus motion that reinforces the page's structure rather than just decorating it.

Development

  • Built the before/after comparison slider from scratch with the Pointer Events API — dragging the handle or clicking anywhere on the image updates a CSS custom property that controls the reveal width, with pointer capture so dragging stays smooth even if the cursor moves faster than the handle.
  • The mobile nav drawer uses GSAP to animate in, with each nav link staggered in on a separate timeline rather than the drawer just appearing instantly.
  • Section titles are split into individual characters at runtime and animated in with a staggered GSAP reveal, rather than animating the whole heading as one block.
  • Workout and blog sections use Slick carousel with per-breakpoint responsive settings, so slide count adjusts properly across screen sizes rather than staying fixed.

UI Screens

Challenges & What's Next

  • Making the comparison slider feel smooth on both mouse and touch — solved with the Pointer Events API instead of separate mouse/touch handlers, since it unifies both input types into one set of event listeners.
  • Currently in progress: the enquiry form doesn't submit anywhere yet — no action, method, or JS handler behind it. Next step is wiring it to a real form endpoint (e.g. Formspree) or a simple backend.
