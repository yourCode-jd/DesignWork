Case Study

TaskFlow

A multi-page task management dashboard with real routing, a working task table, and a live analytics chart.

Role: UI/UX + Frontend React · React Router · Recharts

Goal

Build a working multi-page dashboard with real client-side routing, a fully functional task list — not just a static mockup table — and a genuine chart rather than a placeholder image.

Development

  • Built with React 19, Vite, and React Router DOM. A layout route wraps every inner page (Dashboard, Tasks, Teams, Analytics, Settings, Profile) with a shared sidebar and header, so that layout is defined once rather than duplicated per page, plus a dedicated 404 route.
  • The Tasks page has a fully working table: adding a task goes through a validated form with per-field error messages, deleting removes it immediately, and the search bar filters the visible list in real time.
  • The Analytics page uses Recharts, composed with ResponsiveContainer so the chart resizes correctly rather than being a fixed-size embed.

UI Screens

Challenges & What's Next

  • Structuring routing so every inner page shares one sidebar/header shell — solved with a React Router layout route rendering an Outlet, instead of duplicating the shell per page.
  • Currently in progress: Dashboard's stats and Recent Activity are static and don't yet reflect real task data, since there's no shared state between pages yet — and tasks don't persist across a refresh. Both are the next features going into this project.
