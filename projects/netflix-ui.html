Case Study

Netflix UI Clone

A high-fidelity streaming UI focused on layout precision and smooth interactions.

Role: UI/UX + Frontend React · UI Engineering · Interaction

Goal

Recreate the core Netflix browsing experience — a featured banner, categorized rows, live search, and a detail view — backed by real, live movie data from the TMDB API, using clean, reusable component patterns rather than one-off code per section.

Development

  • Built with React 19 and Vite. A single reusable Row component takes a fetch function as a prop and handles its own data loading via useEffect — so "Trending Now," "Top Rated," and "Action Movies" are each just a Row with a different data source, instead of three near-duplicate components.
  • Search is debounced in the Navbar — a 500ms timeout/cleanup pattern — so a request only fires once the user pauses typing, not on every keystroke.
  • Search results and the selected movie for the detail modal are lifted into the page component and passed down as props, keeping data flow predictable.

UI Screens

Challenges & Solutions

  • Avoiding duplicated fetch logic across categories — solved by making Row accept a fetch function as a prop rather than hardcoding a category inside it.
  • Search performance — firing an API call on every keystroke would hammer TMDB's rate limits, solved with a debounce so the call only fires after the user pauses.
  • The TMDB API key was originally hardcoded in the source and committed to the repo — moved to an environment variable, with the key itself regenerated after the fact.

Tech Stack & Links
